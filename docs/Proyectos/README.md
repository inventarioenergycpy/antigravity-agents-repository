# 🚀 Índice de Proyectos e Repositorios Dedicados

Esta sección de la Bóveda de Obsidian contiene las fichas de registro y seguimiento de cada proyecto desarrollado por los distintos agentes AI en sus **repositorios de GitHub independientes**.

---

## 📌 Protocolo de Registro de Proyectos

Cada vez que un agente cree un nuevo proyecto (Showroom Web, Análisis de Datos, Herramienta Financiera u otro), generará una nota en este directorio (`docs/Proyectos/YYYY-MM-DD_<nombre-proyecto>.md`) con la siguiente plantilla:

```markdown
---
type: proyecto
proyecto: "<Nombre del Proyecto>"
agente_responsable: "[[<Nombre-del-Agente>]]"
repositorio_github: "https://github.com/inventarioenergycpy/<nombre-proyecto>"
despliegue_url: "https://inventarioenergycpy.github.io/<nombre-proyecto>/"
fecha_creacion: YYYY-MM-DD
tags:
  - #proyecto
  - #github
---

# Proyecto: [<Nombre del Proyecto>]

## 🎯 Objetivo y Alcance
- <Descripción ejecutiva del proyecto y su propósito de negocio>

## 🔗 Repositorio y Despliegue
- **GitHub Repo**: [inventarioenergycpy/<nombre-proyecto>](https://github.com/inventarioenergycpy/<nombre-proyecto>)
- **URL Live / Demo**: [GitHub Pages](https://inventarioenergycpy.github.io/<nombre-proyecto>/)

## 👤 Agente Responsable
- [[<Ficha-Agente-en-Docs>]]

## 📂 Entregables y Documentación Asociada
- Documentación interna dentro del repositorio del proyecto (`/docs/`).
- Documentos de Google Workspace asociados en Google Drive.
```
