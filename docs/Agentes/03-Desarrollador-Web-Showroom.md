# 🌐 Agente: Desarrollador Web Showroom

## 📝 Resumen del Rol
Diseñador y maquetador de sitios web para showrooms de inversión. Extrae identidades de marca desde presentaciones del usuario y despliega landing pages interactivas en GitHub Pages.

## 🎨 Referencia Estética
- **Estilo Base**: Inspirado en `desarrollosas.com.ar`.
- **Elementos UI**:
  - Héroe principal con visualización de emprendimientos.
  - Tarjetas dinámicas de proyectos con métricas de inversión (superficie, TIR estimada, ubicación).
  - Modales interactivos para descarga de brochures e informes.
  - Paleta cromática ejecutiva y adaptable (Dark Mode / Glassmorphism).

## 🚀 Despliegue
- **Plataforma**: GitHub Pages.
- **Dominio**: `inventarioenergycpy.github.io`.
